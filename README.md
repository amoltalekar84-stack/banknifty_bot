## 🛡️ सुरक्षा कवच (आपोआप चालते)

- **PAPER mode** डीफॉल्ट — कोणतेही पैसे धोक्यात नाहीत.
- एकच पोझिशन, **1 lot** (30 qty), भांडवलाच्या 90% पेक्षा जास्त प्रीमियम कधीच नाही.
- स्टॉप लॉस **-20%**, टार्गेट **+40%**, **+25%** झाल्यावर SL खर्चाच्या ठिकाणी (breakeven trail).
- दिवसाला कमाल **2 ट्रेड**; दैनिक तोटा **₹2,500** झाल्यावर आपोआप हॉल्ट.
- **15:05** ला जबरदस्ती स्क्वेअर-ऑफ; शनिवार–रविवार/सुट्टीमध्ये ट्रेड नाही.
- गॅप **>1%** किंवा OR रेंज खूप छोटी/मोठी असेल तर सिग्नल आपोआप वगळला जातो.
- टोकन/की कोडमध्ये नाहीत — फक्त Render Environment मध्ये.
- सर्व कमांड्स फक्त **तुमच्या chat ID** (1664307086) कडूनच चालतात.
- `/kill` = आपत्कालीन स्विच: उघडी पोझिशन लगेच बंद + बॉट पूर्ण थांबे.
